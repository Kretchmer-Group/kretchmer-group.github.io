### TiDES

[TiDES](https://github.com/jskretchmer/TIDES) (Time-Dependent Electronic Structure) is our primary
code for real-time electronic structure theory. It is backended with the open-source electronic
structure library [PySCF](https://github.com/pyscf/pyscf) and can currently perform dynamics
calculations using density functional theory and Hartree–Fock. TiDES is built to be modular, so
additional methods and calculation types can be added without reworking the core.

[Real-Time Density Matrix Embedding Theory](https://github.com/jskretchmer/real_time_pDMET) is also
available as a separate code.
